# lochin-wilde.github.io

*[English version](README.md) — основная. Этот перевод для удобства.*

Личный сайт Лочина Уайльда — композитора, саунд-дизайнера и звукорежиссёра.
Открыт по адресу **[lochin-wilde.github.io](https://lochin-wilde.github.io)**.

Три файла, без сборки и без зависимостей:

| Файл | Роль |
|---|---|
| `index.html` | Вся страница. В нём же лежит русский текст статической разметкой |
| `styles.css` | Оформление, подстраивается вплоть до 375 пикселей |
| `main.js` | Словари RU/EN, появление блоков при прокрутке, меню для узких экранов |

## Как править тексты

Каждая переводимая строка существует **дважды**: в объекте `translations` в
`main.js` и как запасной текст внутри элемента с соответствующим атрибутом
`data-i18n`.

Менять нужно оба места сразу. Словарь — это то, что читает посетитель; разметка
— то, что индексируют поисковики и что видно до загрузки скрипта. Однажды они
уже разошлись: страница рассказывала про услуги веб-разработчика, а заголовок —
про композитора. В браузере такое не заметно, потому что скрипт переписывает
текст через несколько миллисекунд после загрузки.

## Язык

Страница открывается на русском, если у браузера локаль `ru-*`, иначе на
английском; переключатель RU/EN перекрывает это решение на время сессии. В
`index.html` проставлено `lang="ru"` и лежит русский запасной текст, а
`applyLanguage()` обновляет и то, и другое.

## Безопасность

GitHub Pages раздаёт статику и не умеет задавать заголовки ответа, поэтому
политика безопасности содержимого едет в теге `<meta>`. Она устроена как
`default-src 'none'` плюс свои же CSS и JS — ни CDN, ни аналитики, ни встроенных
виджетов, под которые пришлось бы делать исключения.

Две защиты так передать нельзя: `frame-ancestors` и `X-Frame-Options` внутри
мета-тега игнорируются, поэтому встраивание страницы в чужой фрейм не
блокируется. На странице нет ни форм, ни входа, ни сохранённого состояния, так
что перехватывать через фрейм нечего; закрыть это по-настоящему можно только
переездом на хостинг, умеющий заголовки.

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Дальше откройте `http://127.0.0.1:8000/`.

## Публикация

Публикует сам факт отправки в ветку `main`. GitHub Pages собирает из корня
ветки — настраивать и запускать нечего.
